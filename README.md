Weather Forecast Project
Description
This is a simple weather forecasting project that uses the OpenWeatherMap API to provide weather information for a city. The user can choose between Celsius and Fahrenheit temperature units.

Features
Retrieve the weather forecast for a user-provided city.

Choose between displaying the temperature in Celsius or Fahrenheit.

Display data such as:

Current temperature

Feels like temperature

Humidity

Weather description

Country of the city

How to Use
Clone this repository:
git clone https://github.com/NicolasssCarlos/weather-forecast.git

Create a config.py file at the root of the project and add your OpenWeatherMap API key. The content of the config.py file should be:
api_key = "YOUR_API_KEY"

Run the Python script:
python weather.py

Enter the name of a city when prompted.

Choose your preferred temperature unit.
